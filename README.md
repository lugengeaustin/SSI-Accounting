# SSI Accounting — Web App (Vite + React + TypeScript + Tailwind + PWA)

The complete, hostable frontend for the SSI Accounting system. It talks to the existing **Supabase** backend (Postgres + Auth + RLS + Edge Functions). This is the React port of the Phase‑1 app, structured to grow into the full system (document engine, master wizard, granular reports).

## Stack

- **React 18 + TypeScript** (Vite)
- **Tailwind CSS** with SSI Editorial Precision tokens (`tailwind.config.ts`)
- **react-router-dom** for routing
- **@supabase/supabase-js** (typed against the live DB — see `src/lib/database.types.ts`)
- **vite-plugin-pwa** (installable / offline-ready shell)

## Prerequisites

- Node.js 18+ and npm

## Run locally

```bash
cd "Web App Projects/SSI-Accounting"   # this project folder
npm install
npm run dev          # http://localhost:5173
```

`.env` is already filled with the SSI Accounting Supabase URL + publishable key (the publishable key is safe in the browser; Row‑Level Security protects the data). To point at a different project, edit `.env` (template in `.env.example`).

First run: click **Create the first account** → that becomes the **admin**. Add colleagues under **Team** (admin only), then they can self‑register.

## Build & host (when ready)

```bash
npm run build        # outputs static files to dist/
npm run preview      # preview the production build locally
```

Deploy `dist/` to any static host — **Netlify, Vercel, or Cloudflare Pages**. Two things to set on the host:

1. **Environment variables**: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` (or commit `.env` — the key is publishable).
2. **SPA fallback**: redirect all routes to `/index.html` (Netlify: `/* /index.html 200`; Vercel: a rewrite to `/`).

No backend to deploy — Supabase is already live.

## Implemented now (full suite)

- **Auth** — allow‑listed signup, first user = admin, auto‑confirm
- **Dashboard** — cash, revenue/expense/surplus, outstanding imprests, review queue, recent activity
- **Receipts** — OCR review queue, add/correct, post to ledger
- **Transactions** — double‑entry editor with live balance check; entry inspector
- **Imprests** — request → approve → issue → retire with auto‑reconciliation
- **Invoices** — create with line items + VAT, issue (posts A/R + revenue + VAT), record payment, PDF
- **Projects** — engagements with per‑project financials (invoiced / received / imprest issued vs retired)
- **Contacts** — clients & vendors
- **Master Wizard** — guided historical backfill (project → invoices → expenses) with **Excel import**
- **Documents** — branded **PDF and editable Word (.docx)** for invoices, payment vouchers, receipts, imprest retirements & project retirements
- **Budgets** — per-project budgets with Budget-vs-Actual variance
- **Analytics** — charts: revenue by domain, expense mix, monthly cash flow, receivables aging
- **Reports** — period-aware **P&L, Balance Sheet, Trial Balance, Cash Flow** (date range / as-at) plus Cash Book, VAT Return, WHT, A/R Aging, Budget vs Actual, Projects, Imprests — with **drill-down to transactions** and **CSV / Excel / Word** export on each
- **Report Explorer** — custom builder: group the ledger by account / category / project / domain / month, pick a measure and filters → live table + chart + export
- **Compliance** — company/tax settings (TIN/VRN, fiscal year, WHT rates), VAT return, WHT receivable/payable, **period lock + year-end close**, audit log, **role-based access** (admin / accountant / officer / viewer)
- **Settings** — company & tax, FX rates editor, Chart-of-Accounts management
- **Team** — admin user/allow-list management
- **Access & offline** — role-based permissions enforced by RLS · offline receipt capture with auto-sync · receipt image / PDF attachments (Storage)
- **Scheduled packs** — monthly financial snapshots auto-generated by `pg_cron`, on the Monthly Packs page
- **Automation** — **Recurring** entries (rent/internet/salaries, auto-posted with WHT), **Fixed Assets** register with straight-line depreciation + Net Book Value, and a **Withholding Tax** register with one-click TRA remittance; daily live FX rates

## Backend functions (Supabase)

Edge functions: `receipt-intake` (n8n → review queue), `docgen` (branded `.docx`), and `update-fx` (daily FX rates). RPCs: double-entry posting, imprest issue/retire, invoice issue/pay, period & year-end close, period-aware statements (`fn_pnl`, `fn_trial_balance`, `fn_balance_sheet`, `fn_cash_flow`), recurring posting (`fn_post_due_recurring`), depreciation (`fn_run_depreciation`), WHT remittance (`fn_remit_wht`), and monthly snapshots (`fn_snapshot_month`). Scheduled with **pg_cron** (monthly packs, daily recurring, monthly depreciation, daily FX). Reporting via SQL views incl. a line-level **`v_ledger`** (drill-down + Report Explorer), `v_asset_register`, `v_wht_register`. Storage buckets: `receipts`, `documents`.
